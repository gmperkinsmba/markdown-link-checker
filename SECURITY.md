# Security

Markdown Link Checker scans a folder you select and reports broken links and flagged paths. It does not save scan state. The app runs with the file access granted to your Mac account, so choose a folder you intend to inspect. File names and paths can be sensitive; use a made-up folder when sharing a report. SHA-256 is not needed for ordinary link checking and would not hide file names or contents.

The scan reads files allowed by your account permissions. Use your Mac’s disk encryption to protect saved files. The native app has an ad-hoc code signature. This lets the installer check whether its files changed. It does not prove who made the app. The build is not notarized.

Report security issues through [GitHub private vulnerability reporting](https://github.com/gmperkinsmba/markdown-link-checker/security/advisories/new).
